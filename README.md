# ERA-PROD — Catalogue de location en ligne

Site statique du catalogue de location de matériel audiovisuel ERA-PROD (Cocody, Abidjan).

- `index.html` : le site complet (catalogue, recherche par description, panier, commande WhatsApp, réservation, contrat).
- `img/` : photos des appareils et des packs.

Aucune installation : ouvrir `index.html`, ou publier le dossier sur un hébergement statique (GitHub Pages, Vercel…).
